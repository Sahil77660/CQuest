Question12:
Enter a four characters from users and check they are equal or not ?
C program/Syntax
#include <stdio.h>
void main()
{
    char ch1,ch2,ch3,ch4;

    printf("Enter first character = ");
    scanf(" %c",&ch1);

    printf("Enter second character = ");
    scanf(" %c",&ch2);

    printf("Enter third character = ");
    scanf(" %c",&ch3);

    printf("Enter fourth character = ");
    scanf(" %c",&ch4);

    if(ch1==ch2 && ch2==ch3 && ch3==ch4)
        printf("All characters are equal");
    else
        printf("Characters are not equal");
}
Input 
                    
Enter first character = a
Enter second character = a
Enter third character = a
Enter fourth character = a
Output 
                    
All characters are equal
