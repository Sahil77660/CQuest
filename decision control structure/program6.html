Question6:
Enter a number from the user if it is a negative then convert into positive and if it is positive then convert into negative often that print the number ?
C program/Syntax
#include <stdio.h>
void main()
{
    int num;

    printf("Enter a number = ");
    scanf("%d",&num);

    if(num<0)
        num = num * -1;
    else if(num>0)
        num = num * -1;

    printf("Number = %d",num);

}
Input 
                    
Enter a number = -89
Output 
                    
Number = 89
