Question11:
Enter a number from user and check it is divisible by 4 or not ?
C program/Syntax
#include <stdio.h>
void main()
{
    int num;

    printf("Enter a number = ");
    scanf("%d",&num);

    if(num%4==0)
        printf("Number is divisible by 4");
    else
        printf("Number is not divisible by 4");
}
Input 
                    
Enter a number = 56
Output 
                    
Number is divisible by 4
