Program 09
Question9:
Enter two character from user and print ASCII value ?
C program/Syntax
#include <stdio.h>

void main()
{
    char a, b;

    printf("Enter first character: ");
    scanf(" %c", &a);

    printf("Enter second character: ");
    scanf(" %c", &b);

    printf("\nASCII value of %c = %d", a, a);
    printf("\nASCII value of %c = %d", b, b);

}
Input
Enter first character: h
Enter second character: f
Output 
Entered 4 character = 
ASCII value of h = 104
ASCII value of f = 102
