Question2:
Write a program to show that example of post-increment ?
C program/Syntax
#include <stdio.h>

void main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d",&number);

    printf("Value before post-increment = %d\n",number);
    printf("Value after post-increment = %d",number);
}
Input 
                    
Enter a number: 5
Output 
                    
Value before post-increment = 5
Value after post-increment = 6
