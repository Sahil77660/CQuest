Program 03
Question3:
Write a program to show that example of pre-decrement ?
C program/Syntax
#include <stdio.h>
void main()
{
    int number=10;

    printf("Number before pre-decrement = %d\n",number);
    printf("Number after pre-decrement = %d",--number);

}
Input 
                    
number = 10
Output 
                    
Number before pre-decrement = 10
Number after pre-decrement = 9
