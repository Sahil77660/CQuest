Program 22
Question22:
Enter a character from user and that character should be alphabet ?
C program/Syntax

#include <stdio.h>

void main()
{
    char ch;

    printf("Enter a character: ");
    scanf("%c",&ch);

    if((ch>='A' && ch<='Z') || (ch>='a' && ch<='z'))
    {
        printf("%c is an alphabet",ch);
    }
    else
    {
        printf("%c is not an alphabet",ch);
    }
}
Input 
                    
Enter a character: A
Output 
                    
A is an alphabet
