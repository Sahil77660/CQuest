Program 17
Question17:
Enter a number from user and find out factorial of that number ?
C program/Syntax

#include <stdio.h>

void main()
{
    int num, i, factorial=1;

    printf("Enter a number: ");
    scanf("%d",&num);

    for(i=1; i<=num; i++)
    {
        factorial=factorial*i;
    }

    printf("Factorial of %d = %d",num,factorial);
}
Input 
                    
Enter a number: 5
Output 
                    
Factorial of 5 = 120
