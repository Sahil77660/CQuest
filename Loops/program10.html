Question10:
Write a program print the table of 4 in the format given as below (till 20)?
4*1=4 and so on
C program/Syntax

#include <stdio.h>

void main()
{
    int i;

    for(i=1; i<=20; i++)
    {
        printf("4 * %d = %d\n",i,4*i);
    }
}
